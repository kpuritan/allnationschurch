🐙 GitHub 저장소 연동 & 전세계 자동 배포

관리자 모드에서 등록한 설교와 폴더를 GitHub 저장소(kpuritan/allnationschurch)로 바로 커밋(Commit)하여, 모든 기기(스마트폰, 다른 PC 등)에서 항상 최신 말씀이 보이도록 배포합니다.

⚪ GitHub 연동 대기: 아래에 GitHub 개인 액세스 토큰(Personal Access Token)을 1회 등록하시면, 버튼 한 번으로 깃허브 서버에 즉시 영구 저장됩니다.

📌 GitHub 토큰 발급 1분 가이드 (최초 1회만 등록)

GitHub 계정에서 토큰을 발급받아 위에 입력하시면, 웹 관리자 모드에서 수정할 때마다 깃허브가 자동으로 업데이트됩니다.

  1. GitHub 토큰 발급 페이지 ↗로 이동하여 로그인합니다.
  2. Note에 AllNations Church CMS 입력
  3. Expiration(유효기간)을 No expiration(무제한) 또는 원하는 기간으로 선택
  4. Select scopes 항목 중 repo(저장소 전체 권한) 체크박스를 선택
  5. 맨 아래 초록색 [Generate token] 버튼 클릭 후 생성된 ghp_... 토큰 복사 ➔ 위의 입력창에 붙여넣기

💾 데이터 백업, 내보내기 & 복원

등록한 모든 강해 폴더와 설교 영상 데이터를 JSON 파일로 안전하게 백업하고 복원할 수 있습니다.

💡 안내: 관리자 모드에서 등록하신 모든 폴더와 설교는 즉시 브라우저 로컬 저장소에 안전하게 보관되어 홈페이지에 실시간 반영됩니다. 정기적으로 '데이터 JSON 다운로드'를 눌러 백업 파일을 보관해 두시면 더욱 안전합니다.
